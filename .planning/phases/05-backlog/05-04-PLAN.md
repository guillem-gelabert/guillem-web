<objective>
Prove the backlog in production, re-point the launch gate, close the backlog leg on the record, and
ship it.

Three things here are easy to get silently wrong.

**The build tier cannot be run against a stale `.next`.** `test:build` reads bytes off disk; it does
not produce them. The harness throws a legible error when `.next/server/app` is *missing* — it
cannot detect *stale*. A deleted stub assertion will pass against yesterday's HTML and prove
nothing.

**The raw prerendered file says `dateTime`, not `datetime`.** React 19.2.8 emits the JSX prop name
verbatim; browsers ASCII-lowercase it during parsing, so Playwright's `getAttribute("datetime")`
works while a build-tier `includes('datetime="…")` fails. The obvious diagnosis — "the date didn't
render" — is wrong. Measured in the shipped build.

**A launch gate that shrinks toward triviality stops being read.** After this phase only the contact
stub remains interim, while **three** copy-review items are outstanding and all three block Phase 6's
`FIND-02` robots flip: `HOME-01`'s unwritten positioning sentence, the user's editorial pass over
both case studies, and now the backlog item copy. Phase 4 established the treatment at
`prerender.test.ts:531-538`. Follow it — narrow the part that closed, and re-point the gate at what
is still open.
