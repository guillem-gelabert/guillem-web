<objective>
FIND-02's plumbing: the sitemap and robots file a search engine indexes the site *through*. Both are
ordinary prerendered static routes hanging off the content module the indexes already use, and both
were prototyped and verified against a real build in `06-RESEARCH.md`.

The binding constraint comes from `tests/build/prerender.test.ts`'s own closing forward note: the
sitemap must call `publishedFor()`, not re-derive the draft rule. `draft: true` then keeps a piece
out of the sitemap for free and no second source of truth appears.

This plan does not flip robots and does not make the site indexable. `robots: { index: false }`
stays on both root layouts and is inherited by every route. A `robots.txt` saying `Allow: /` while
every page carries a `noindex` meta tag is the correct intermediate state — the meta tag wins, and
the file is ready for the user's own flip.

Purpose: the two metadata routes, and the deletion of the framework scaffold assets that would
become crawlable the moment that flip lands.
Output: `app/sitemap.ts`, `app/robots.ts`, five fewer files in `public/`.
</objective>
