<objective>
Retire the stale Dockerfile-based deploy path and stand up a bare Next.js 16 scaffold at a live,
stable Railway URL, before any design work begins (CONTEXT.md D-08 — deploy first, then design).

Purpose: Every commit after this plan is a known-good increment. The repo's existing root
`Dockerfile` silently wins Railway's builder-selection over the already-configured Railpack
builder, with no override possible — confirmed live against the Railway API. Retiring this on
day one closes PITFALLS #1 and #4 before the typographic system exists to be undermined by it.
Output: A committed, pushed Next.js scaffold; the live Railway URL
(`web-production-9cedb.up.railway.app`) serving it, confirmed via an automated Playwright smoke
test run against the real deployed URL — not just a local dev server.
</objective>
