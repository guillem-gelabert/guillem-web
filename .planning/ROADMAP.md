# Roadmap: Guillem Web

**Created:** 2026-05-04
**Mode:** Interactive
**Granularity:** Standard
**Execution:** Sequential

## Overview

This roadmap turns the ultra-minimal MVP into three focused phases. The sequencing keeps the early work anchored on the core branded hero, then adds the motion and responsive craft that make the page feel intentional, and finishes with deployment and positioning validation.

**Phases:** 3  
**v1 requirements:** 12  
**Mapped requirements:** 12  
**Coverage:** 100%

## Phase Details

### Phase 1: Identity Foundation

**Goal:** Establish the minimal product shell: a React-based single-page site with a full-screen hero, Guillem's name as the dominant visual element, and a working GitHub exit point.

**Requirements:**
- LAND-01
- LAND-02
- POSI-01
- LINK-01
- TECH-01

**Success Criteria:**
1. A React application renders a single-page website without requiring additional sections or routes.
2. The first viewport is dominated by Guillem's name in a way that clearly identifies the site as his personal presence.
3. A GitHub link is visible or discoverable within the MVP and opens the correct destination.
4. The page structure is simple enough to support later motion work without reworking the app shell.

### Phase 2: Motion and Visual Craft

**Goal:** Add the hero behavior and visual treatment that make the page feel authored, creative, and technically sharp rather than like a static placeholder.

**Requirements:**
- LAND-03
- INTX-01
- INTX-02
- TECH-03

**Success Criteria:**
1. Scrolling produces a clear, intentional transformation in the hero typography.
2. The interaction remains readable and stable rather than glitchy or disorienting.
3. The page reads as visually distinctive on both desktop and mobile layouts.
4. The overall look feels deliberate enough to support the site's role as a hiring asset for creative and editorial-adjacent roles.

### Phase 3: Positioning and Launch

**Goal:** Make the first-screen impression legible to the target audience and publish the MVP so it can be used in the job search.

**Requirements:**
- POSI-02
- POSI-03
- TECH-02

**Success Criteria:**
1. The first-screen experience gives enough cues that a recruiter, editor, or studio can place Guillem in the data visualization / data journalism / creative dev space.
2. The site leaves a strong impression of creativity, technical craft, and broad curiosity even with minimal copy.
3. The MVP is deployed successfully on Railway and accessible via a stable public URL.
