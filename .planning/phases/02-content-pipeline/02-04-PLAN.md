<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| URL `[slug]` → `loadPostModule` dynamic import | The only request-derived value that reaches a module specifier anywhere in the site |
| `content/*.md(x)` → prerendered HTML | Author-supplied Markdown, JSX and YAML become the page |
| Public asset paths → `<img src>` | Fixture SVGs served from `public/` |

ASVS V2, V3, V6 and V13 remain inapplicable. V7 applies only in the negative: no error boundary is
added, deliberately, so a malformed post keeps failing `next build` instead of degrading at request
time.

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-16 | Tampering / Information disclosure | Path traversal through `[slug]` into `import(\`@/content/${slug}.mdx\`)` | mitigate | `findBySlug(await publishedFor("en"), slug)` runs and `notFound()` is thrown **before** `loadPostModule`. Task 1's acceptance criteria assert the call order by line number, and Task 3 asserts it behaviourally by requesting a German slug from the English route. |
| T-02-17 | Information disclosure | A draft URL prerendered into a production build | mitigate | `generateStaticParams` maps `publishedFor("en")`, which applies `isVisible`. Asserted against real build output in Plan 07. |
| T-02-18 | Tampering | Raw HTML smuggled through a `.md` post | mitigate | `@mdx-js/mdx` drops raw HTML in `format: 'md'`; `rehype-raw` is not installed and must not be added. `content/nur-auf-deutsch.md` carries a literal `<Aside>` tag precisely so this stays a tested property, asserted in Plan 06. |
| T-02-19 | Elevation of privilege | `content/fixture.mdx` importing a React component | accept | Deliberate (D-08) and bounded: content is repo-committed and reviewed (D-11), and the import resolves against the repo's own `components/` tree at build time. Never render MDX from a fetched or user-supplied source. |
| T-02-20 | Information disclosure | `generateMetadata` emitting an `hreflang` for a draft German twin | mitigate | The twin is resolved through `translationOf`, which filters on `isVisible`, so a production build emits no alternate for an unpublished translation. |
</threat_model>
