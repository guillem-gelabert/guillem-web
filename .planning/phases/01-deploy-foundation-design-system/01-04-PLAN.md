<objective>
Port the scroll-driven heading-trail effect from `text_trail_demo/index.html`'s
`createTextShadowEffect` + shared `frame()` driver, generalized from the demo's single-heading
tab-switcher into a registry that drives every Humane-set heading in this app off one shared
`requestAnimationFrame` loop — then wire it onto the holding page's `<h1>` and the `/type`
specimen's Display/Heading samples, gated by `prefers-reduced-motion` before any frame is ever
scheduled.

Purpose: This is HOME-06 and BUILD-05, the phase's one motion feature and its accessibility gate.
It is explicitly a PORT, not a rebuild — the algorithm, constants, and settle logic are read
directly from the benchmark and carried across with exactly one required deviation (monochrome ink
instead of the demo's rainbow hue-cycling) and one required generalization (one shared loop over a
registry instead of one `activeEffect`).
Output: Three new files under `components/smear-heading/`, the provider mounted in
`app/layout.tsx`, both routes' Humane-set headings wired to it, and two new Playwright specs.
</objective>

**use-prefers-reduced-motion.ts contract:**
```ts
'use client'
export function usePrefersReducedMotion(): boolean
```
Wraps `matchMedia('(prefers-reduced-motion: reduce)')` inside `useEffect` only — never at module
top-level or during render (`window` does not exist during SSR). Updates live via the matcher's
`change` listener (mirrors `text_trail_demo/index.html:1066`), not just an initial read (Pitfall 6).

**smear-heading-provider.tsx contract:**
```tsx
'use client'
export function SmearHeadingProvider({ children }: { children: React.ReactNode }): JSX.Element
export function useSmearHeadingRegistry(): {
  register: (el: HTMLElement, documentTop: number) => void
  unregister: (el: HTMLElement) => void
}
```
Owns the only `requestAnimationFrame` call in the whole tree. Holds `registry: Map<HTMLElement, {
documentTop: number; lagY: number }>` in a ref, never in React state. `frame()` iterates the
registry each tick and writes `el.style.textShadow` directly (never `setState`).

**use-smear-heading.ts contract:**
```ts
export function useSmearHeading<T extends HTMLElement>(): React.RefObject<T>
```
On mount (`useLayoutEffect`, after `document.fonts.ready` resolves), measures
`getBoundingClientRect()` and calls `register(el, rect.top + scrollY)`. On unmount, calls
`unregister(el)` and clears any inline `textShadow` left on the element.
</interfaces>
